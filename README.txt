# ITTEFAQ PAINT Website

This is a standalone HTML/CSS/JavaScript recreation of the visible ITTEFAQ PAINT website design.

## Free publishing
Upload `index.html`, `style.css`, and `script.js` to a public GitHub repository.
Then open:
Settings → Pages → Deploy from a branch → `main` → `/root` → Save.

The site does not require Durable hosting.

## Before publishing
Replace the text/contact details if any business information has changed.
